# Seva Progressive Web App

## How to setup

Rename `.env.example` to `.env` and add your environment variables.

Execute [Yarn](https://yarnpkg.com/lang/en/docs/cli/create/) to install all the dependencies:

```bash
yarn
```

Then, execute `yarn dev` to bootstrap the application. This will run the application on `http://localhost:3000`

```bash
yarn dev
```
